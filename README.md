# GaitCare

요양원 어르신을 위한 **Android 보행 평가 앱**.
주머니에 넣은 스마트폰의 가속도계·자이로 센서로 보행을 측정하고, 5가지 지표를 종합한 100점 만점 점수와 시계열 기록을 제공합니다.

## 📌 왜 만들었나

요양원에서 어르신들의 **보행 능력은 낙상 위험·인지 저하·전반적 건강 상태**를 보여주는 중요한 임상 지표입니다. 그러나 기존 보행 평가는 전문 장비(GAITRite, Tinetti 평가지)나 임상가의 직접 관찰이 필요하여 일상적인 추적이 어렵습니다.

GaitCare는 **작업치료사가 스마트폰만으로 어르신의 보행을 정기 측정·기록·추세 관찰**할 수 있게 만든 안드로이드 앱입니다.

---

## ✨ 주요 기능

- 🏥 **기관 회원가입 및 로그인** (자동 로그인 지원)
- 👵 **어르신 관리** (등록, 검색, 상세조회, 삭제)
- 📊 **보행 측정** (가속도계 50Hz, 자동 축 캘리브레이션)
- 📈 **시계열 기록 및 추세 분석** (최근 측정 + 평균 점수)
- 💾 **로컬 DB(Room) 저장** (오프라인 동작)
- 🎨 **하늘색/화이트 톤의 노인친화적 UI**

### 요구사항
- Android Studio Iguana 이상
- JDK 17
- Android 8.0 (API 26) 이상 단말


## 🚶 보행 평가 알고리즘 개요

### 측정 환경 가정
- 휴대폰을 **주머니에 임의 방향으로** 넣음 (축은 자동 보정)
- 가속도계 + 자이로스코프 동시 사용, 약 50Hz 샘플링
- 최소 20초 이상 측정 권장

### 처리 흐름
```
[가속도 원시 신호 (50Hz)]
        ↓
[10초 캘리브레이션] — 축 자동 보정 (수직/전방/좌우 식별)
        ↓
[저주파 필터] — 중력 성분 제거 → 동적 가속도 추출
        ↓
[5개 지표 동시 계산]
   ├─ 흔들림     (Lateral·Vertical RMS)
   ├─ 보행 리듬  (Step Interval CV%)
   ├─ 대칭성    (걸음 추진력 비대칭)
   ├─ 회전안정성 (자이로 평균 각속도)
   └─ 보행속도   (Forward Axis RMS)
        ↓
[가중 평균] → 100점 만점 종합 점수
```

### 축 자동 캘리브레이션
주머니 방향이 일정하지 않으므로, 측정 시작 후 10초간 다음 통계로 축을 자동 식별합니다.

| 축 | 식별 기준 |
|----|----------|
| **수직(Z')** | 평균 절댓값 최대 — 중력에 정렬된 축 |
| **전방(Y')** | 분산 최대 — 보행 진동이 가장 큰 축 |
| **좌우(X')** | 나머지 한 축 |

자세한 알고리즘과 수식은 [docs/SENSOR.md](docs/SENSOR.md)를 참고하세요.

## 📊 점수 기준 (요약)

5개 지표를 각각 0~100점으로 변환 후 가중 평균:

`총점 = 흔들림×0.25 + 리듬×0.25 + 대칭성×0.20 + 회전×0.20 + 속도×0.10`

### 지표별 만점(95) ~ 최저점(33) 경계

| 지표 | 95점 | 88점 | 80점 | 72점 | 63점 | 53점 | 43점 | 33점 |
|------|------|------|------|------|------|------|------|------|
| **흔들림 (g)** | <0.08 | <0.15 | <0.22 | <0.32 | <0.45 | <0.62 | <0.85 | ≥0.85 |
| **리듬 CV(%)** | <4 | <8 | <14 | <22 | <32 | <45 | <60 | ≥60 |
| **대칭 SI(%)** | <3 | <6 | <12 | <20 | <30 | <45 | <60 | ≥60 |
| **회전 (°/s)** | <15 | <32 | <52 | <78 | <108 | <145 | <185 | ≥185 |

### 보행속도 (전방축 RMS, g)

| RMS 범위 | 점수 | 의미 |
|---------|------|------|
| 0.13~0.45 | 88~90 | 정상 보행 |
| 0.08~0.13 | 73 | 느린 노인 보행 |
| 0.04~0.08 | 55 | 매우 느린 셔플 |
| <0.04 | 30 | 거의 정지 |

### 종합 점수 등급

| 점수 | 등급 | 색상 |
|------|------|------|
| 80~100 | 매우 좋음 | 🟢 |
| 65~79 | 좋음 | 🟢 |
| 50~64 | 보통 | 🟡 |
| 35~49 | 주의 필요 | 🟠 |
| <35 | 위험 | 🔴 |

## ⚠️ 한계와 가정

학술·임상적 신뢰성을 위해 다음 한계를 명확히 합니다.

- **임상 검증 미실시** — GAITRite·Tinetti·Berg Balance 등 표준 임상 평가와 비교 검증되지 않았습니다. 의료 진단용이 아닌 **참고·추세 모니터링 도구**입니다.
- **점수 기준값 검증 부재** — 점수 경계값은 일반 보행 문헌과 추정에 기반하며, 요양원 어르신 표본으로 검증되지 않았습니다.
- **개인 간 절대 점수 비교 부적합** — 휴대폰 모델, 주머니 위치(좌/우), 바지 두께, 휴대폰 고정 정도가 신호에 영향을 줍니다. **같은 어르신의 시간에 따른 변화** 추적에 더 적합합니다.
- **대칭성 지표의 위치 편향** — 휴대폰이 한쪽 다리 근처에 있어 baseline 비대칭이 항상 존재합니다. 절대값보다 변동을 보세요.
- **느린 셔플 보행 검출 한계** — 매우 약한 보행은 가속도 피크가 작아 걸음 검출 신뢰도가 낮습니다. 보행속도 지표는 이런 경우를 위해 걸음수 카운팅 대신 전방축 RMS를 사용합니다.

## 🗄️ 데이터 저장

모든 데이터는 **기기 내부 Room(SQLite) DB**에 저장됩니다. 서버 전송 없음, 백업 없음.

- 경로: `/data/data/com.inhatc.gaitcare/databases/gaitcare.db`
- 비밀번호는 SHA-256 해시로 저장
- 앱 삭제 시 모든 데이터 소실
- 기기 간 동기화 미지원

테이블 구조:
- `institutions` — 기관 회원
- `elderly` — 어르신 정보 (institution FK, CASCADE)
- `gait_sessions` — 보행 측정 기록 (elderly FK, CASCADE)
